Описание/Пошаговая инструкция выполнения домашнего задания:
Требования к проекту и его технологическому стеку

- Объем, как 3-4 ДЗ (за меру можно взять ДЗ по веб-библиотеке)
- Spring Core
- Spring Security (желательно через JWT, желательно вынести в отдельный сервис)
- Spring MVC/WebFlux
- Bean Validation
- Spring Data Jdbc/Jpa/MongoDB/...
- Коммуникация между микросервисами по REST/очередям (если есть микросервисы)
- Соблюдение всех практик и рекомендаций, которые давались на курсе. В том числе должна быть работа с исключениями
- Юнит и интеграционные тесты приветствуются
- Использование паттернов отказоустойчивости приветствуется (CircuitBreaker/Retry/Cache/ServiceRegistry/ConfigServer/ApiGateway/...)
- Docker приветствуется

Назначение:
Когда клиенты приходят в lounge-бары (кальянные), то они в 99% случаев теряются в ассортименте и уж тем более не ориентируются в сочетаниях вкусов. В итоге заказ максимально абстрактный — вкусное, фруктовое, цветочное и тп.
Приложение "ToMixer" предназначено для упрощения работы барменов/кальянщиков, помощи гостям баров и продвижения услуг заведения.

Архитектура:
Планируется использовать монолитную архитектуру. Если потребуется в ходе разработки, то один из модулей будет отделен в микросервис.

Стек:
- Spring Core
- Spring Boot
- Spring Security
- Spring MVC
- Spring Data
- PostgreSQL
- Docker
- *HTML + CSS + JS для UI

Сценарии использования:
1. Справочник доступных в заведении табаков с указанием характеристик: бренда, крепости, вкуса и тп.
2. Возможность собрать желаемый микс.
3. Сохранение миксов в отдельный справочник с возможность поставить лайк/дизлайк и дальнейшим рейтингом миксов.
4. Рандомный "Микс дня" для спец.цены.
5. *Подбор миксов по критериям.
6. *Генерация купонов, которую можно запускать при заказе от N рублей. Сохранение и активация купонов.
